# Préenregistrement – run de référence Ouroboros

**Date figée :** 2026-10-14  
**Condition :** C3-like (IA + mémoire + réflexion), observation pure, cadre **neutre**.  
**Répétitions :** 1 (observations exploratoires, pas de preuve statistique).

## Hypothèses (qualitatives)

1. Sans grades ni titres imposés par le code, des asymétries d'influence apparaissent via le graphe de déférence.
2. Des pratiques partagées (coutumes, tabous respectés) peuvent diffuser sans injection observateur.
3. La variance inter-agents reste bornée par la taille des modèles ; elle sera mesurée, pas affirmée.

## Indicateurs déclarés avant lancement

- Gini (ressources, influence), entropie comportementale, entropie de spécialisation
- Densité du réseau, centralité de déférence (moyenne / max)
- Comptages tabous / coutumes / croyances ; taux d'anachronisme filtré
- Population, natalité, mortalité infantile estimée
- Décisions IA par année simulée ; empreinte modèle + température
